# paranoid-p5-demo

**Inert research package. Do not depend on it.**

Test fixture for provenance-traceability research (Paranoid, Nullcon Goa 2027).
It exports one constant string and has no install scripts, network access or
filesystem access. Versions are published deliberately to show how an npm
provenance attestation relates (or stops relating) to the repository's history
after force-pushes, side-branch publishes, build-time inputs and moved tags.

Every version will be deprecated after the talk.
